# 基金速查任务

用户输入: $ARGUMENTS

加载 `fund-manager-alpha` skill 的**速查模式**，只做四件事：

1. **任期切割** —— 现任经理管了多久，业绩能不能记在他头上（`fetch_fund.py` 的经理数据）
2. **持有体验** —— 最大回撤、最长水下天数（"买在山顶要熬几年"）
3. **平台分对照** —— pingzhongdata 拉东财五维分，和从业年头/规模一起给个第一印象
4. **申赎压力** —— 总份额近几期是流入还是失血

产出：直接在对话里给一段速查结论（不生成 HTML），格式：

- 一句话定调（谁在开车 · 开了多久 · 车况如何）
- 三个最扎眼的数字，每个都有主语和口径
- 要不要跑完整审计的建议

**不许**给"可以买/不能买"的绝对结论——速查没有做买卖点验尸和独立性取证，证据不足时只能说"值得/不值得花时间深查"。
