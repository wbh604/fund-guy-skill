# 模块合同

每项必须保存 `status`、`conclusion`、`evidence_refs` 和 `reviewer`。状态只允许：`已证实`、`估算`、`未证明`、`未发现可靠公开信息`。

## 基金取证 45 项

| ID | 模块 | 必答问题 | 主审席 |
|---|---|---|---|
| M01 | 产品识别 | 是否主动管理，用户买到的到底是什么策略？ | institutional_skeptic |
| M02 | 任期切割 | 哪段属于现任、共同管理或历史遗产？ | alpha_forensic |
| M03 | 经理依赖度 | 结果有多大比例受个人主观判断支配？ | chief_underwriter |
| M04 | 基础履历 | 履历如何形成今天的能力圈？ | people_investigator |
| M05 | 人物花絮 | 哪些公开私人信息可信且权重为零？ | people_investigator |
| M06 | 牛熊实战 | 牛、熊、震荡、极端和风格切换期分别怎样？ | alpha_forensic |
| M07 | Alpha真实性 | 收益来自市场、行业、风格、选股、择时、平台还是一次性收益？ | alpha_forensic |
| M08 | 运气检验 | 剔除前1/3/5大赢家后还剩多少超额？ | alpha_forensic |
| M09 | 风格漂移 | 行业、市值、估值、市场与风险档位是否改变？ | portfolio_detective |
| M10 | 热点滞后 | 进入热门方向时该方向已涨多少？ | portfolio_detective |
| M11 | 交易人格 | 持有、加减仓、止盈止损和回撤换仓模式是什么？ | portfolio_detective |
| M12 | 言行一致 | 公开观点是否被后续持仓动作兑现？ | people_investigator |
| M13 | 压力人格 | 最大回撤期仓位、集中度、换手和框架如何变化？ | people_investigator |
| M14 | 规模诅咒 | 超额是否随 AUM 扩大而衰减？ | alpha_forensic |
| M15 | 策略容量 | 当前规模是否超过策略最优容量？ | institutional_skeptic |
| M16 | 退出压力 | 减仓相当于多少日成交量，冲击成本多大？ | portfolio_detective |
| M17 | 公司内抱团 | 与同公司产品持仓重合多少？ | portfolio_detective |
| M18 | 同步交易 | 同公司基金是否同期新进、加仓或减仓？ | portfolio_detective |
| M19 | 市场拥挤 | 全公募持有数量、增减持和估值拥挤如何？ | portfolio_detective |
| M20 | 独立决策 | 排除本人并调整主题限制后，敢不敢和同事不一样；不一样时有没有赚到钱？两项永远分开。 | people_investigator |
| M21 | 影子经理 | 组合是否长期跟随另一核心经理？ | portfolio_detective |
| M22 | 平台Alpha | 研究平台贡献多少，离开平台还能剩什么？ | institutional_skeptic |
| M23 | 团队稳定 | 研究员、助理、投资总监流失是否伤害对应 Alpha？ | institutional_skeptic |
| M24 | 产品复制 | 多产品是否只是同一组合换包装？ | portfolio_detective |
| M25 | 申赎冲击 | 规模变化来自净值还是资金进出，被迫交易多大？ | institutional_skeptic |
| M26 | 持有人结构 | 个人、机构、大额与单一持有人稳定性如何？ | institutional_skeptic |
| M27 | 资本标签 | 国家长期资金、险资、社保、年金、FOF、理财、外资、员工、经理谁在持有？ | institutional_skeptic |
| M28 | 资本五要素 | 对每个资本标签确认谁、多少、何时进、多久、最近动作？ | institutional_skeptic |
| M29 | 长钱认可 | 长期资本是持续配置还是单期噪声？ | institutional_skeptic |
| M30 | 机构变化 | 机构占比和具体机构正在进入还是退出？ | institutional_skeptic |
| M31 | 换经理投票 | 换经理前后机构是否继续持有？ | institutional_skeptic |
| M32 | 踩踏风险 | 持有人、申赎、拥挤和流动性会不会共振？ | institutional_skeptic |
| M33 | 伪分散 | 不同行业是否暴露于同一经济驱动？ | portfolio_detective |
| M34 | 排名焦虑 | 排名落后或年末时是否追热点、加 Beta？ | people_investigator |
| M35 | 特殊收益 | 打新、定增、转债等一次性收益贡献多少？ | alpha_forensic |
| M36 | 尾部风险 | 最大回撤、最差月季、下行 Beta 和左尾有多重？ | alpha_forensic |
| M37 | 合规监管 | 严重违法、一般措施或暂未发现异常？ | institutional_skeptic |
| M38 | 核心评分 | 八大一级模块按规定权重得分如何？ | chief_underwriter |
| M39 | Alpha类型 | 选股、择时、平台、行业、伪 Alpha 或无法证明？ | chief_underwriter |
| M40 | Alpha可复制率 | 历史超额未来能复制多少，区间依据是什么？ | chief_underwriter |
| M41 | 首页指标 | 哪些十项指标足以支撑首屏判决？ | chief_underwriter |
| M42 | 一句话结论 | 能不能买，最大本事和最大硬伤是什么？ | chief_underwriter |
| M43 | 搜索与证据 | 每项结论的来源等级、报告期、页码和截止日是什么？ | institutional_skeptic |
| M44 | 事实硬规则 | 是否触犯任期、Beta、持有、国资、抱团或交易推断禁令？ | chief_underwriter |
| M45 | 产品定位 | 今天交钱后，历史能力还有多大概率继续存在？ | chief_underwriter |

## Manager / People 24 项

| ID | 项目 | 必答问题 |
|---|---|---|
| P01 | 职业路径 | 他怎样一步步成为今天的经理？ |
| P02 | 能力圈形成 | 哪段工作形成了哪些行业或方法优势？ |
| P03 | 投资哲学 | 他真正相信价值、成长、周期、逆向还是配置？ |
| P04 | 认知方式 | 产业、财务、宏观、量化或交易，哪种主导？ |
| P05 | 决策机制 | 一只股票怎样从发现走到重仓与退出？ |
| P06 | 风险人格 | 亏损后加仓、止损、换仓还是硬扛？ |
| P07 | Conviction | 最看好的股票是否真的敢重仓和长期拿？ |
| P08 | 错误处理 | 判断错后多久承认，怎样退出？ |
| P09 | 学习能力 | 框架是合理进化还是追热点？ |
| P10 | 独立思考 | Idea 是本人先发现还是平台消费？ |
| P11 | 情绪稳定 | 极端行情下行为是否失常？不能从采访语气猜。 |
| P12 | 诚信一致 | 说的和做的是否一致？ |
| P13 | 利益一致 | 自购、限购、发新基金和规模激励是否一致？ |
| P14 | 职业野心 | 更偏 Investment-first、AUM-first 还是 Career-first？ |
| P15 | 平台依赖 | 离开现平台还剩多少能力？ |
| P16 | Key Person Risk | 产品是否本质上就是这个人？ |
| P17 | 能力形成时间线 | 市场怎样训练和修正了他？ |
| P18 | 哲学持久度 | 早期、中期、现在的核心框架是否稳定？ |
| P19 | 行为DNA | 下跌、上涨、回撤、集中和换手的真实模式是什么？ |
| P20 | 错误档案 | 代表性错误、原逻辑、后续行为和教训是什么？ |
| P21 | 先手发现 | 是本人先发现、平台共创，还是跟着平台买？ |
| P22 | 认知边界 | 他知道什么不做，新领域是否有学习过程？ |
| P23 | Manager × Regime | 人的方法为什么适合或不适合特定市场？ |
| P24 | Career Incentive Profile | 路演、发新、接管、限购、行政职位透露什么动机？ |
